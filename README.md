# Bank Customer Churn Prediction

A data science project focused on predicting whether a bank customer is likely to leave the institution.

## Objective

Build and evaluate classification models to identify customers at risk of churn and support customer-retention strategies.

## Repository Structure

```text
bank-customer-churn/
├── data/

├── notebooks/               # Exploratory analysis and modeling notebooks

```
